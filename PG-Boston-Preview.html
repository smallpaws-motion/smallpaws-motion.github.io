📐 Usage Guide

วิธีนำไปใช้

✅ ใช้ PG Boston สำหรับ
  • Hero headline หลัก (70–96px)
  • Section titles เช่น "งานที่ผ่านมา." (48–56px)
  • Contact section headline "มาพูดคุยกัน ♡"
  • Card titles ชื่อ service (24–32px)
  • About headline "สวัสดี เราคือ SmallPaws 👋"
❌ ใช้ Inter แทนสำหรับ
  • Body text / paragraph descriptions
  • Navigation links และ button text
  • Section labels / badges / tags
  • UI text เช่น input fields, captions
  • ตัวเลข stats เช่น "8+" (Inter Black ดูเท่กว่า)
CSS — นำไปใส่ใน style.css ได้เลย
/* ── PG Boston Custom Font ── */
@font-face {
  font-family: 'PG Boston';
  src: url('PG Boston.ttf') format('truetype');
  font-weight: normal;
  font-style: normal;
  font-display: swap; /* ป้องกัน FOUT */
}

/* ── CSS Variable ── */
:root {
  --font-display: 'PG Boston', Georgia, serif;
  --font-body:    'Inter', system-ui, sans-serif;
}

/* ── Apply ── */
.hero-title, .section-title, .card-title {
  font-family: var(--font-display);
}
body, .btn, .nav, p, label {
  font-family: var(--font-body);
}
