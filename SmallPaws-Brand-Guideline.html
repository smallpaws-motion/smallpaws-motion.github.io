🗣 Brand Voice

เสียงของแบรนด์

Personality · Tone · Do & Don't

🎯
Expert but Approachable
พูดแบบมืออาชีพที่มีประสบการณ์ แต่ไม่ formal จนน่ากลัว เหมือนเพื่อนที่เชี่ยวชาญและช่วยได้จริง
🩷
Warm & Caring
ใส่ใจทุก brief, iterate จนพอใจ, ส่งงานตรงเวลา — สื่อสารให้รู้สึกว่าคุณสำคัญเสมอ
✨
Creative & Playful
ใช้ emoji เสริมบุคลิก (🐾🎬✦🩷), ภาษาสนุก, ไม่แข็งกระด้าง — สะท้อนความครีเอทีฟในงาน
💪
Confident & Honest
พูดตรง ชัดเจน ไม่อ้อมค้อม — "Revise ได้จนพอใจ", "ส่งงานตรงเวลาเสมอ" — ไม่โอ้อวดแต่มั่นใจ
✅ DO — ควรทำ
  • ใช้ภาษาเป็นกันเอง "เรา", "คุณ" ไม่ใช่ "ทาง SmallPaws Motion"
  • จบ headline ด้วย . หรือ ~ ที่เป็นสีชมพู (PG Boston)
  • ใช้ emoji ประกอบบุคลิก (🐾 🎬 ✦ 🩷 ✨)
  • ใช้ "iterate จนพอใจ", "ใส่ใจทุก brief" — value ชัดเจน
  • Pink สำหรับ action/emphasis, Violet สำหรับ creative/secondary
  • PG Boston สำหรับ Headline ที่ต้องการ character
❌ DON'T — ห้ามทำ
  • อย่าใช้ PG Boston สำหรับ body text หรือ UI elements
  • อย่าใช้ Pink + Violet ติดกันโดยไม่มี neutral คั่น
  • อย่าใช้ Pink บน background ที่ contrast ต่ำ
  • อย่าใช้ภาษาทางการมากเกินไป — "ท่านลูกค้า", "กระผม"
  • อย่าใช้สีมากกว่า 2 สี brand ต่อ 1 component
  • อย่าใช้ตัวอักษรขนาดเล็กกว่า 12px สำหรับ body
TONE EXAMPLES — Copywriting
✅ BRAND VOICE
"เราไม่ได้แค่ทำ animation — เราเข้าใจ brief ของคุณ และเปลี่ยนมันให้เป็นงานที่ทั้งสวยและสื่อสารได้จริง 🩷"

"Revise ได้จนพอใจ ไม่มีค่าใช้จ่ายเพิ่ม เป็นส่วนหนึ่งของทุกโปรเจกต์"
❌ OFF-BRAND
"บริษัทฯ ขอนำเสนอบริการผลิตสื่อ Motion Graphic อย่างมืออาชีพ พร้อมบริการหลังการขายที่เหนือระดับ"

"ท่านสามารถติดต่อสอบถามได้ในเวลาทำการ"
{ } CSS Variables

ตัวแปร CSS

คัดลอกไปใส่ใน :root ของ style.css — รวม font tokens

/* SmallPaws Motion — CSS Design Tokens v1.0 */

/* ── Fonts ─────────────────────────────────── */
@font-face {
  font-family: 'PG Boston';
  src: url('PG Boston.ttf') format('truetype');
  font-display: swap;
}

:root {
  --font-display: 'PG Boston', Georgia, serif;  /* Headlines */
  --font-body:    'Inter', system-ui, sans-serif; /* Body/UI */

  /* ── Primary: Hot Pink ── */
  --pink:       #FF3D8B;
  --pink-50:    #FFF0F6;
  --pink-100:   #FFD6E8;
  --pink-200:   #FFB3D4;
  --pink-300:   #FF7DB2;
  --pink-600:   #CC0060;

  /* ── Secondary: Violet ── */
  --purple:     #7C5CFC;
  --violet-100: #EDE9FE;
  --violet-200: #C4B5FD;
  --violet-300: #A78BFA;
  --violet-600: #5B21B6;

  /* ── Dark BG (Website) ── */
  --dark:       #0F0D1E;
  --dark-2:     #1A1730;
  --dark-3:     #252240;

  /* ── Neutrals ── */
  --gray-400:   #9CA3AF;
  --gray-500:   #6B7280;
  --gray-300:   #D1D5DB;
  --white:      #FFFFFF;

  /* ── Gradients ── */
  --grad-primary: linear-gradient(135deg, #FF3D8B, #7C5CFC);
  --grad-soft:    linear-gradient(135deg, #FFB3D4, #C4B5FD);

  /* ── Semantic ── */
  --success: #06D6A0;
  --warning: #FBBF24;
  --error:   #EF4444;
}
